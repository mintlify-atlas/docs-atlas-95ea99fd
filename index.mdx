Better-NiDA brings the standard Khmer NiDA keyboard layout to macOS and Linux by reverse-engineering the Windows `kbdkni.dll` driver down to its raw binary tables. Every character assignment — 49 keys across four modifier states and five multi-character ligatures — is verified against Windows itself at 144/144 comparisons with zero mismatches, then generated into `.keylayout` bundles for macOS and XKB symbols files for Linux.

## What Better-NiDA provides

Better-NiDA ships two layout variants on both platforms, faithfully matching the two Windows drivers:

<CardGroup cols={2}>
  <Card title="Khmer NiDA" icon="keyboard" href="/reference/nida-vs-legacy">
    The modern standard: coeng `្` on `J`, zero-width space on `Space`, 4 modifier states. Matches `kbdkni.dll` exactly.
  </Card>
  <Card title="Khmer NiDA Legacy" icon="clock-rotate-left" href="/reference/nida-vs-legacy">
    The legacy variant: coeng on `Space`, real space on `Shift+Space`, with a fifth `Shift+AltGr` level exposing the full Khmer symbol block `U+19E0–U+19FF`.
  </Card>
</CardGroup>
