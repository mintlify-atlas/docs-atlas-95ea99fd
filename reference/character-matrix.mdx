This is the complete character mapping for the Khmer NiDA keyboard layout, derived from reverse-engineering `kbdkni.dll` — the Windows keyboard driver for KLID `00010453`. The main character table covers **49 keys** across **4 modifier states**: Normal, Shift, Control, and AltGr. The Control state emits `0xF000` (no character) for every printable key in the NiDA driver — NiDA overrides no control characters — so it is omitted from the table below. The three useful states are Normal, Shift, and AltGr.

Invisible characters are labelled explicitly throughout:

| Label | Code Point | Name |
| :-- | :-- | :-- |
| `<ZWSP>` | U+200B | Zero-width space |
| `<ZWNJ>` | U+200C | Zero-width non-joiner |
| `<ZWJ>` | U+200D | Zero-width joiner |
| `<NBSP>` | U+00A0 | Non-breaking space |

**LIGATURE entries** emit two code points in a single keystroke. ## Invisible and Formatting Characters

Six keys emit characters that produce no visible glyph. These are essential for correct Khmer text segmentation and script shaping:

| Character | Code Point | Input | Purpose |
| :-- | :-- | :-- | :-- |
| Coeng ្ | U+17D2 | `J` | Subscript generator — placed before a consonant to render it as a subscript (e.g. ក + ្ + ខ) |
| Zero-width space | U+200B | `Space` | Separates Khmer words without a visible gap |
| Space | U+0020 | `Shift+Space` | A real, visible space character |
| Non-breaking space | U+00A0 | `AltGr+Space` | Non-breaking space — prevents line breaks at this position |
| Zero-width non-joiner | U+200C | `AltGr+1` | Suppresses a coeng joining where an explicit break is wanted |
| Zero-width joiner | U+200D | `AltGr+\`` | Forces joined script forms where they would otherwise be suppressed |

The most important of these is the coeng on `J` and the spacebar behaviour: unlike most keyboard layouts, pressing `Space` alone inserts a zero-width space (U+200B) for Khmer word segmentation. To insert a visible Latin-style space, press `Shift+Space`.
